# Последний сигнал — starter pack

В архиве: мастер-промпт, сценарная библия, 6 оригинальных SVG-фонов, 5 стилизованных SVG-портретов-заглушек, 6 оригинальных коротких WAV-петель и небольшой браузерный прототип.

**Важно:** это комплект материалов и каркас, а не уже законченная новелла на час. Передайте архив модели, которая умеет работать с файлами и программировать, вместе с `MASTER_PROMPT_RU.md`. Она должна развернуть сценарий, добавить ветвления, графику и проверить готовую игру.

## Запуск
Откройте `index.html` или запустите локальный статический сервер.

## GitHub Pages
1. Создайте репозиторий GitHub.
2. Загрузите всё содержимое этой папки в корень ветки `main`.
3. Откройте Settings → Pages.
4. Выберите Deploy from a branch → `main` → `/(root)` → Save.
5. Откройте опубликованный URL.

Используются относительные пути; backend не нужен. Сохранения браузерного прототипа хранятся в localStorage.

Все SVG и WAV в пакете созданы программно специально для проекта. Временные портреты — placeholders, не финальный арт.

## Что реализовано в версии 2
Меню (новая игра/продолжить/главы/галерея/персонажи/настройки), 6 глав, 50 вариантов выбора, 4 характеристики, флаги отложенных последствий, 3 финала с персональными эпилогами, автосохранение и ручное сохранение, пропуск прочитанного, история реплик, плавная смена музыки, громкость музыки/эффектов, скорость текста.
## Ограничения
Главы 1–4 развёрнуты; главы 5–6 короткие. Портреты — сгенерированные векторные (SVG), не нарисованы по фото; 10 фонов; CG нет.
